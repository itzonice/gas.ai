# Licenses

Everything StudyPulse ships or builds with, where it came from, and its license
(launch safety S27). `pnpm licenses:check` runs in CI and fails on any GPL, AGPL,
source-available, or unreviewed license; `pnpm licenses:check --write` regenerates the
dependency table below.

## Fonts

| Font                                                                                     | Where                                       | Source                                                    | License                                                                                  |
| ---------------------------------------------------------------------------------------- | ------------------------------------------- | --------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Roboto, or the system sans (`system-ui`, San Francisco, Segoe UI, Helvetica Neue, Arial) | Web (`--sp-font-sans` in `packages/tokens`) | Installed on the device; nothing is downloaded or bundled | Roboto: Apache-2.0. System fonts are licensed to the device and not redistributed by us. |
| System font                                                                              | Mobile                                      | The platform default (San Francisco, Roboto)              | Part of iOS and Android; not redistributed                                               |

No web font files are bundled or loaded from a font CDN.

## Marketing copy

Checked the app, web pages, emails, and store text in this repo: no testimonials,
reviews, user counts, ratings, "#1" claims, or outcome promises (such as grade
improvements). The only product claims are the plan limits, which are read from
`@studypulse/core/plans`. Before publishing any testimonial, keep written permission
from the person and make sure it reflects a typical result; before any comparative or
numeric claim, keep the data that supports it.
